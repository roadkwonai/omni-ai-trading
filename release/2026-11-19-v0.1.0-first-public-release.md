# Omni AI Trading v0.1.0 — 첫 공개 릴리스

[HKUDS Vibe-Trading](https://github.com/HKUDS/Vibe-Trading)(MIT) 위에 국내 시장 자동매매와 미국 ETF 장기투자를 더한 Omni AI Trading의 첫 공개 버전입니다. NH투자증권 나무 PLUG OpenAPI로 시세를 읽고 주문합니다. 판단은 AI가 하고, 주문은 승인된 규칙과 주문 가드가 정합니다.

- 소개 페이지: https://roadkwonai.github.io/omni-ai-trading/
- 리포트 목록: https://roadkwonai.github.io/omni-ai-trading/reports/
- 가이드 문서: [docs/README.md](https://github.com/roadkwonai/omni-ai-trading/blob/main/docs/README.md)

> [!IMPORTANT]
> 기본은 **모의계좌**입니다. 실계좌는 계좌별 실주문 스위치(확인 문구), 실행 플래그 `--execute`, 계좌별 하루 손실 한도(최대 2만 원)를 모두 통과해야 주문합니다. NH투자증권과 제휴·후원 관계가 없는 비공식 프로젝트이며, 투자 조언이 아닙니다.

## 담긴 것

### Jev 실시간 트레이딩

- 장중 1분마다 회차를 돕니다. NH 시세·1분봉을 읽고, Jev가 차트 이미지와 최근 90분 뉴스로 후보를 고릅니다.
- 진입 경로는 Jev 후보·관심종목 강도·신규상장 3가지이고, 병렬 전략 슬롯이 있습니다. 강도·신규상장 슬롯은 Jev가 ETF를 고른 회차에도 먼저 평가됩니다.
- 분할 매수와 추가 매수는 횟수·크기·'직전보다 나은 조건'으로 조절합니다. 매수 비중은 보유량과 시황에 맞추고, 손절은 국면 방향을 반영해 좁힙니다. 청산 프로필은 방어형·추세형·인버스 빠른 익절이 있습니다.
- 인버스는 지수 국면·당일 하락·반등 여부·프로그램 수급·전날 나스닥 다섯 조건이 모두 하락을 가리킬 때만 삽니다.
- 같은 날 재진입은 국면이 불리하면 신중 재진입(추격·약세 받기 금지, Jev 재검토, 크기 50%)을 거칩니다.
- 낙폭과대 경로는 둘입니다.
  - 장중 반등: 시장 폭락일에만 삽니다.
  - 선별 v2: 14:30~14:55에 분할 진입하고, 평균가 +8%·+15%에서 분할 익절합니다. −2%에 손절한 뒤에는 저점에서 다시 판단해 재매수합니다.
  - 근거 자료로 10년 사례집과 재현 기록이 있습니다.
- NXT 애프터마켓 종가매매는 가상 체결로만 학습합니다.

### 실계좌

- 계좌마다 운용 방식을 고릅니다. Jev 트레이딩(모의 체결 미러)과 장기투자 중 하나입니다.
- Jev 미러는 모의 체결을 금액 비례로 따라 하며, 체결별 몫은 처음 본 값으로 고정합니다. 모의가 다 팔면 실계좌도 다 팝니다.
- 보호 한도
  - 운용금은 계좌 잔고 안에서 정합니다.
  - 하루 손실은 계좌별 최대 2만 원입니다.
  - 1주 가격 상한, 하루 새 종목 5개 제한이 있습니다.
  - 미체결·미확인 주문이 있으면 새 주문을 막습니다.
  - KRX 장 시간 점검이 있습니다.
- 대시보드에서 즉시 매도와 수동 매수·매도를 요청할 수 있습니다. 요청은 모두 같은 보호 경로를 거칩니다.

### 장기투자

- 대상은 국내 상장 미국 지수·테마 ETF 6종이고, 기준 비중은 코어 60 · 위성 25 · 저수지 15입니다. 매일 아침 나스닥100 낙폭·200일선·VIX로 국면 6개 중 하나를 정합니다.
- 거장 모듈 8개가 목표 비중을 조정합니다. 모듈은 계좌별로 고를 수 있고, 거장별 수치도 편집할 수 있습니다. 12주 분할 투입과 레시피 비교 장부가 있습니다.
- 적립식 v3: '언제'와 '얼마나'를 각각 거장 자동이나 내가 정하기로 고릅니다. 금액 기준과 종목별 N주 기준, 매수 시각, 종목·수량 제한, 미체결 재매수를 지원합니다.
- 여운봉 저수지 매매법: 나스닥100 전고점 대비 −20/−30/−40%에서 단계 매수하고, 매월 70:30으로 리밸런싱합니다.
- 저수지(투자할 종목이 없을 때 현금을 두는 곳) ETF를 장부마다 KOFR · CD금리 · 단기채권 중에서 고릅니다. 자동이면 운용금 1,000만 원 미만은 1주 가격이 절반인 CD금리를 씁니다.
- 가상 1억 원 계좌로 먼저 검증합니다. 주문마다 근거를 묶어 남기고, 매일 복기·주간·월간 감사를 합니다.
- 미국 종목 아이디어(버핏·린치·피셔 스크린, 13F)는 참고 정보이며 주문하지 않습니다.

### 기록·리포트·알림

- 매매일지는 일·월·분기·반기·연 단위로 쓰고, 같은 템플릿과 검사를 거칩니다.
- 장 마감 개선안, 장전 상세 분석, 장기투자 전략 리포트·복기를 씁니다.
- 리포트는 HTML로 GitHub Pages에 발행하고, Discord에는 링크를 보냅니다.
- Discord 알림은 실시간·장기 두 채널입니다. 매도 손익과 15:40 계좌별 마감 요약을 보냅니다.

### AI와 함께 쓰기

- Claude Code·Codex로 채팅하며 운영합니다. 설치 프롬프트, 지침 파일 템플릿, 프로젝트 스킬 9개 설치(Codex 연결 포함), vibe-trading MCP 연결, 읽기 전용 권한, 예약 작업 15개 등록, 상황별 프롬프트 예시를 [AI와 함께 쓰기](https://github.com/roadkwonai/omni-ai-trading/blob/main/docs/ai-agents.md)에 모았습니다.
- 채팅하는 AI는 조회·분석·보고·요청만 합니다. 주문은 실행기와 주문 가드만 냅니다.

### 운영

- Streamlit 대시보드는 10개 탭을 세 묶음(매일 · 계좌 · 관리)으로 나눴고, 가이드 센터 팝업과 Archify 흐름도를 씁니다. 관리 묶음의 '운영' 탭에 운영 상태 · 자동 작업 · AI·실행 기록 · API 연동 · 스킬 · 리포트 발행 · 백업·이식 화면이 있습니다.
- '성과 비교' 탭은 Jev 트레이딩과 장기투자의 손익·수익률·낙폭·국면별 성적·두 방식의 관계를 같은 날짜로 비교하고, 날짜 × 장부 기록을 쌓아 CSV로 내려받습니다.
- '자동 작업' 화면에서 launchd 서비스·Claude 예약 작업·Codex 자동화를 날짜별 시각 순으로 봅니다.
- launchd 서비스와 Claude 예약 작업으로 돌립니다. 장전 사전 점검(08:20·08:53)과 매시 장중 감사를 하고, 문제 이력으로 재발을 추적합니다.
- 읽기 전용 실행기 `scripts/ro`가 있어, 예약 작업이 승인 대기로 멈추지 않습니다.
- 백업·이식: 설정 정리본, 전체 백업 아카이브, 예약 작업 백업으로 새 계정·새 컴퓨터에 복원합니다.

## 2026-11-19 변경

- **개장부터 주문:** 09:00~09:09 주문 없는 관찰을 없앴습니다. 주문이 개장(09:00)부터 나가고, 손절도 09:00부터 나갑니다. 실제 첫 진입 판단은 완료 분봉 6개가 쌓이는 09:08 무렵입니다.
- **이월 포지션 개장 판단:** 종가베팅·이월·스윙 포지션은 09:00~09:07에 전날 마지막 분봉을 더해 Jev 보유 판단을 받습니다.
- **NXT 프리마켓 요약:** 08:00~08:50 체결을 요약해 Jev 판단의 장전 맥락으로 넣습니다. 참고 입력이며, 프리마켓 실제 매매는 하지 않습니다.
- **실계좌 미러:** 모의 신규상장주 매수도 따라 삽니다. 선별 v2 매수 창(14:30~14:55)도 따릅니다.
- **진입 후보 막힘 방지**
  - 1주도 못 사는 관심종목 강도 후보는 고르지 않습니다.
  - 주문 단계에서 사지 못한 후보는 10분 동안 후보에서 뺍니다.
  - 같은 거절이 3분 이어지면 장중 감사가 잡습니다.
- **실계좌 가드:** 체결·취소로 끝난 주문과 지문이 같은 새 주문은 받습니다. 미해결 주문은 계속 막습니다.
- **장기투자**
  - 계좌별 수치 설정을 지웠습니다. 모든 장부가 엔진의 기준 비중·운용 수치를 씁니다.
  - 적립식 수량 기준에서도 거장이 금액을 정할 수 있습니다.
  - 여운봉 매매법은 매월 리밸런싱하고, 못 산 몫은 단계 매수분만 넘깁니다.
- **Discord 매도 표기:** '🛑 손절'은 손실이 난 손절일 때만 씁니다. 다 판 매도는 '전량 매도'로 표기합니다.
- **기록 DB 보호:** SQLite 파일을 밖에서 열고 닫던 코드를 없앴습니다. 원장 색인 손상의 원인이었습니다. 장중 감사가 DB 무결성을 확인합니다.
- **대시보드 메뉴 재구성:** 14개 탭을 10개 세 묶음으로 줄였습니다. '엔진 비교'는 '성과 비교'(Jev 트레이딩 vs 장기투자)로 바꾸고, 주문·정리는 실계좌 탭으로 옮겼습니다. 예전 탭 이름과 주소는 새 자리로 열립니다.
- **장기투자 저수지 ETF 선택:** 장부마다 KOFR · CD금리 · 단기채권을 고릅니다. 다른 저수지 ETF를 들고 있으면 가상 계좌는 다음 매매에 옮기고, 실계좌는 다 판 뒤부터 바꿉니다.
- **NH 유량 초과 줄이기:** 순위 계산이 5분마다 60종목을 몰아서 조회해 다른 서비스 호출까지 함께 거절되던 문제를 고쳤습니다. 조회 간격을 초당 2회로 띄우고, 거절되면 1초 뒤 다시 묻습니다. 장중 감사가 같은 문제의 재발을 잡습니다.
- **체결 기록 차트:** 종목 × 거래일 지도와 거래일별 매수·매도 금액 막대로 바꿨습니다.

## 설치

```bash
git clone https://github.com/roadkwonai/omni-ai-trading.git
cd omni-ai-trading
```

이후 순서는 [시작하기](https://github.com/roadkwonai/omni-ai-trading/blob/main/docs/getting-started.md)를 따릅니다. `.env.example`을 복사해 키를 직접 넣고, 첫 회차는 모의계좌에서 확인합니다.

## 알려진 제한

- macOS(launchd) 운영을 전제로 합니다.
- 모의 성과와 가상 체결은 실제 체결이나 수익성 검증이 아닙니다. 낙폭과대·적립식 재현은 과거 일봉·분봉 규칙 재현입니다.
- 이 저장소는 운영 저장소의 공개용 스냅숏입니다. 원본 Vibe-Trading의 커밋 이력은 이어 붙이지 않았고, 출처는 README·LICENSE·NOTICE에 남겼습니다. 운영 설정 정리본, 예약 작업 지시문, 내부 설계·감사 문서는 공개 범위에서 뺐습니다.
- 토스 시세의 외부 AI 전달 정책은 아직 정하지 않았습니다. 그래서 원본 봉이 아닌 요약값만 보냅니다.
