# Omni AI Trading v0.1.8 — 자동 작업과 거래 운영 개선

운영 화면에 자동 작업의 일정과 AI 모델, 실행 이력을 모으고 트레이딩 기록과 진단 기능을 개선했습니다.

## 자동 작업

- Claude 예약 작업과 Codex 자동화, macOS 서비스를 한 목록에서 검색하고 최근 실행순 또는 이름순으로 정렬합니다.
- 작업별 일정과 최근 실행, 설정 모델 및 확인된 모델을 보여주고 상세 창에서 보존된 이력을 살펴볼 수 있습니다.
- 지원하는 리포트와 감사 작업은 작업별로 Claude 또는 Codex 모델을 선택할 수 있습니다. 전환 조건과 실행 결과를 화면에서 확인합니다.

## 트레이딩 운영

- 실계좌 미러와 주문 보호, 시세 조회 및 거래 데이터 기록을 보완했습니다.
- 장중 감사와 뉴스·시황 수집, 장기투자 리포트와 매매일지의 관측과 진단을 개선했습니다.
- 진입과 청산 관련 관측 및 재현 기록을 확장했습니다.

## 확인 범위

기존 매매 설정과 주문 보호 조건을 유지하면서 실행기와 운영 화면의 관련 테스트를 수행했습니다. 자동 작업의 실행 이력은 각 실행 환경이 보관한 기록 범위에서 표시됩니다.
