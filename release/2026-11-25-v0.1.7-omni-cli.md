# Omni AI Trading v0.1.7 — omni CLI와 AI 에이전트 연동

터미널과 여러 AI 에이전트에서 같은 명령으로 기록을 조회하고 설정 변경을 계획하는 **omni CLI**를 더했습니다. 소개 페이지, README, 가이드를 정리했고 Windows·Linux에서 쓰기 위한 준비를 시작했습니다. 매매 규칙과 기준값, 주문 한도는 바뀌지 않았습니다.

## omni CLI

- `omni status`, `omni jev blocks`, `omni lt today`처럼 명령 한 줄로 잔고, 거래, 매수하지 않은 이유, 장기투자 판단, 리포트를 조회합니다. 모든 명령에 `--json`을 붙일 수 있고, 답에는 자료의 시각과 주의 사항이 함께 나옵니다.
- Claude Code와 Codex를 비롯해 셸 명령을 실행할 수 있는 에이전트라면 전용 플러그인 없이 같은 명령을 씁니다. 프로젝트 스킬 `omni-cli`와 [가이드](https://github.com/roadkwonai/omni-ai-trading/blob/main/docs/omni-cli.md), [명령·설정 참조](https://github.com/roadkwonai/omni-ai-trading/blob/main/docs/omni-cli-reference.md)를 함께 제공합니다.
- 설정은 **계획 → 영향 확인 → 승인 → 적용** 순서로 바꿉니다. 실계좌에 영향을 주는 변경과 매매 요청은 알림 채널로 보낸 일회용 승인 코드를 사용자가 알려 줘야 적용됩니다. 실주문 켜기, HALT 해제, 백업 가져오기는 확인 문구도 필요합니다.
- 증권사에 직접 주문하거나 새 종목을 사는 명령은 없습니다. 매매 요청은 실행기와 주문 가드를 거칩니다. 실계좌의 신규 매수 중단(`omni live pause`)만 승인 코드 없이 바로 적용됩니다.
- AI 검색도 명령으로 씁니다. 내 기록으로 답하는 질문은 무료이고, 웹 검색과 질문은 요금을 확인하는 `--yes`가 있어야 전송합니다.

설치는 [README의 omni CLI 절](https://github.com/roadkwonai/omni-ai-trading#omni-cli)에 있는 프롬프트나 명령 두 줄로 합니다.

## 소개 페이지와 문서

- 소개 페이지에 눌러 보는 CLI 예시, 승인 4단계, 에이전트 연결 그림, 설치 안내를 넣었습니다.
- README와 가이드 전체의 한국어 문장과 용어를 다듬고, 지금 동작과 달라진 설명을 고쳤습니다(새 뉴스가 없을 때의 판단, 장기 뉴스 범위, 자동 실행 서비스 수와 시각 등).

## 장기투자 기록과 알림

- 적립식이 오늘 사지 않은 이유와 사는 조건을 화면, 기록, 전략 리포트에 적습니다. 적립식 주문 계산은 그대로입니다.
- 그날 거래에 쓴 장부 설정을 남겨, 장중에 바꾼 전략은 비교용 장부에도 다음 거래일부터 적용합니다.
- 저녁 리포트가 정한 시각까지 나오지 않으면 알림 채널로 한 번 알립니다.

## 안정성

- `accounts.json`이 있는데 읽을 수 없으면 모의 자동매매를 끈 것으로 보고 저장도 거절합니다. 예전에는 새로 설치한 것처럼 켜진 상태로 읽었습니다.
- 자동 실행 서비스의 상태를 물어볼 수 없으면 '실행 안 함'이 아니라 '확인 불가'로 다루고, 거래일 시작·재시작·백업 가져오기를 거절합니다.
- 설정 변경 이력에 누가 바꿨는지(화면, 에이전트 이름)를 남깁니다.
- 파일 잠금, 글자 인코딩, 서비스 관리를 운영체제에 맞게 나눴습니다. `omni ops service-files`가 Windows·Linux용 서비스 정의 파일을 만들며, 등록은 직접 해야 합니다.

## 확인한 내용

실행기·매매·장기투자·대시보드 테스트 2,588개, 주문 보호·도구 관련 테스트 1,081개, omni CLI 테스트 378개가 통과했습니다. 실제 시험은 Claude 에이전트와 macOS에서 했습니다. 다른 AI 에이전트, 실제 Windows 실행, 승인 절차 전체를 실주문으로 실행하는 것은 아직 확인하지 않았습니다. 실행기와 실계좌 경로의 파일 잠금·인코딩 변경은 11-25 거래일에 처음 적용되어 실제 장에서는 아직 확인하지 못했습니다.
