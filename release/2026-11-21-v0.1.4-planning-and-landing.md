# Omni AI Trading v0.1.4 — 기획서와 서비스 소개 보완

Omni를 만든 이유와 장중 모의매매·장기투자 기능을 더 쉽게 이해할 수 있도록 기획서, 가이드와 소개 페이지를 보완했습니다.

## 달라진 점

- 서비스가 해결하려는 문제, 사용자 여정, 기능별 요구사항과 아키텍처를 [기획서](https://github.com/roadkwonai/omni-ai-trading/tree/v0.1.4/PRD)에 정리했습니다. 개발 시작 프롬프트와 단계별 검증 기준도 담았습니다.
- README와 가이드에 노후 준비 배경, 금융이해력 조사, 장기투자와 입금형 적립식의 사용 방법을 보완했습니다. 개장 직후 판단과 실계좌 보호 조건 안내를 현재 구현에 맞췄습니다.
- 소개 페이지에 노후 소득 자료, 실제 재무상담 사례와 개장 판단 개선 사례를 추가했습니다. 장중 모의매매와 장기투자 경로를 첫 화면에서 선택할 수 있습니다.
- 공개 리포트의 템플릿 검사 시점과 실계좌 수치 자동 가림의 한계를 가이드에 명시했습니다.

- 기존 Vibe-Trading 다국어 README를 `docs/vibe-trading/`으로 옮기고 패키지·Docker·문서 생성 경로를 갱신했습니다.

## 확인한 내용

랜딩페이지 프로덕션 빌드와 면책 문구 테스트를 통과했습니다. 모바일과 데스크톱에서 주요 버튼, 도표와 장기투자 화면을 확인했습니다.

공개 배포본에는 Jev 모의 실행기가 간접 참조하는 전략 모듈이 빠져 있어 깨끗한 설치에서 Jev 모의 실행과 일부 관련 테스트가 중단됩니다. 시세 연결과 설치 제한은 [시작하기](https://github.com/roadkwonai/omni-ai-trading/blob/v0.1.4/docs/getting-started.md#공개-v013-설치-후-확인)에서 확인할 수 있습니다.
