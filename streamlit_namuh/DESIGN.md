# Omni AI Trading 화면 설계

## 목적과 사용자 흐름

개인 사용자가 모의계좌의 보유·주문·AI 판단을 먼저 확인하고, 실계좌는 별도 화면에서 확인하는 운영형 대시보드다. 모의계좌의 보유·진행을 첫 탭으로 배치하고 모의 주문, 모의 AI 차트, 실계좌, 운영 상태를 분리한다.

## 정보의 의미

- 증권사 전체 페이지 조회로 확인한 잔고·주문과 로컬 AI 의견·주문 원장을 구분한다.
- 계좌 유형, 자료 출처, 한국시간 조회 시각, 오래된 자료와 조회 실패를 명시한다. 실패는 빈 잔고나 미체결 0으로 표현하지 않는다.
- 체결 확인 시각은 증권사의 실제 체결 시각이 아니다. Jev·Decision 의견은 주문이나 체결이 아니며 신뢰도는 수익 확률이 아니다.
- 모의와 실계좌 설정은 별개다. 실계좌는 인버스 전용으로, 모의 학습의 실계좌 자동 적용은 검증되지 않았다.

## 종합 현황

ETF 현황 맨 위에 계좌 평가손익(수익률), 보유 ETF 종·주 수, 오늘 확인 체결 매수·매도 건과 주식 수, 최근 Jev 의견을 카드로 둔다. 보유 종목마다 ▲수익/▼손실 배지와 손절(-2%)~익절(+2%) 사이 현재가 위치 막대를 표시한다. 한국 관례대로 수익은 빨강, 손실은 파랑이며 색과 함께 기호·문자로 구분한다. 2분보다 오래된 잔고로는 요약을 표시하지 않는다.

그 아래 계좌 잔고(주문가능금액·총매입·총평가, 증권사 응답 그대로, 1억 이상은 억 단위·도움말에 원 단위)와 종목별 손익 표를 둔다. 표는 보유했거나 이 실행기가 거래한 ETF만 보이며, 평가손익은 증권사 응답, 실현손익(오늘·누적)은 로컬 확인 체결의 이동평균 매입가 기준이다. 원장을 읽지 못하면 실현손익 미확인 경고를 낸다. 주문가능금액은 총자산으로 합산하지 않는다.

## 차트와 손익

### 장기투자 실계좌

- 상단 상태 카드는 장기투자 실행기와 계좌 전략, 신규 매수, 주문 보호를 보여줍니다. 자산·보유 탭에 오늘 계획 건수, 주문 접수 기록, 매수·매도 체결, 최신 실행 사유와 적립식 일정·대기 자금을 배치합니다. 주문·체결 탭에서 계획과 증권사 체결의 상세 표를 봅니다.
- **자산·보유**는 증권사에서 잔고를 읽고 마지막 성공 조회 시각과 종목별 현재가·평가금액·평가손익·수익률을 표시합니다. 새로고침 실패 시 이전 성공 결과에 실패 안내를 붙이고, 성공 기록이 없으면 체결 원장으로 확인 가능한 보유 수량과 평균 매입가를 표시합니다.
- **장기투자 대시보드**는 설정 운용금, 기록 실현손익, 저수지 ETF를 자산 카드에 포함합니다. 비중 비교는 종목별 한 줄에서 평가 막대와 목표선을 같은 척도로 보여주고 표에 비중 차이와 금액을 표시합니다. 평가 미확인 값은 비워 둡니다. 아래에 실보유 종목과 일별 총자산을 배치하고, 일봉·주봉과 체결 마커는 보유 차트를 펼쳤을 때 불러옵니다.

### 트레이딩 차트

첫 화면에 보유 종목을 우선 선택한 TradingView 차트와 최근 Jev 의견을 함께 배치한다. 선택 종목의 NH 완료 1분봉을 조회해 저장 분봉과 결합하고 판단·체결 마커를 표시한다. AI 의견 마커는 의견이 바뀐 시점에만, 보유분 Jev SELL은 실행 기준(신뢰도 0.7) 이상일 때만 표시한다. 체결 마커는 수량을 표시하며, 해당 분봉이 저장되지 않았으면 다음 분봉에 실제 확인 시각을 붙인다. 여러 번 매수한 보유분은 순보유가 0에서 시작된 매수 시점부터 증권사 평균매입가를 기준선으로 쓴다. 화면에서 30초 자동 조회를 선택할 수 있으며, 마지막 분봉과 증권사 조회 시각을 표시하고 조회 실패 시 저장 기록임을 알린다. 텍스트와 가격 표도 제공한다. 최근 증권사 보유와 로컬 확인 체결이 일치할 때에만 보유 확인 시각 이후의 매입가·손절·익절 기준과 가격 위아래 영역을 표시한다. 평가 기준 가격 구간은 수수료와 세금이 반영된 순손익이 아니다.

## 반응형 및 접근성

Streamlit의 기본 레이아웃과 명시적 제목·입력 레이블을 우선한다. 가로 공간이 부족하면 표와 영역을 순서대로 배치한다. 수익·손실, 매수·매도, 오류는 색만이 아니라 문자·기호·마커 모양으로 구별한다. 자동 조회는 선택적 30초 REST이며 틱 단위 스트림이 아니다.

## 안전 상태

실행기 프로세스와 주문·체결은 다른 상태다. 손절 감시는 실행기가 작동할 때만 수행되며 2% 가격 체결을 보장하지 않는다. 미확인 주문, 보호매도 미전송, 오래된 판단과 거래 시간 밖 상태는 경고한다. 실계좌 시작·중단은 기존 보호 경로를 그대로 사용한다.

## Jev 판단 근거

차트 아래에 최근 Jev 진입 판단의 후보·신뢰도(진입 기준 0.60)·선택지별 확률과, 같은 주기에 기록된 실제 입력(7 ETF 최근 1분 종가를 첫 분 대비 %로, 뉴스 헤드라인과 발행 시각, 오늘 기사가 아니면 표시)을 보여준다. Jev 입력은 차트와 헤드라인뿐임을 명시하고, 시세·투자자별 일별 순매수는 "참고 시장 데이터(Jev 입력 아님)"로 분리해 버튼 또는 자동 조회 시 5분 간격으로만 조회한다. 오늘 투자자 행은 장중 잠정치로 표시한다. 차트는 매분 Jev 의견을 작은 표시로 모두 찍고 의견이 바뀐 시점에만 글자·신뢰도를 붙이며, 보유 종목이 없으면 최근 Jev 후보 종목을 기본 선택한다.

## 2026-11-11 리디자인 (ui-ux-pro-max)

- 스킬 디자인 시스템 중 대시보드에 맞는 요소만 채택: 다크·미니멀(Swiss)·고밀도. 테마는 저장소 루트 `.streamlit/config.toml`(배경 #020617, 카드 #0E1223, 강조 #22C55E). 수익 빨강/손실 파랑은 한국 시장 관례를 유지하고 ▲▼·부호·글자를 병기한다. 추천 패턴(Enterprise Gateway 랜딩)과 Fira 글꼴은 적용하지 않았다.
- 첫 탭 "모의 트레이딩" 순서: 상태 한 줄(실행기·관찰기·조회 시각·새로고침, 30초 자동 갱신 토글) → 핵심 카드 2×2(평가손익·주문가능금액/평가·매입·보유와 오늘 체결·최근 Jev) → 종목별 손익 표와 손절~익절 위치 막대 → 차트(상태 한 줄, 범례는 "차트 보는 법" 펼침, 최근 90분으로 열림) → 상세 탭(Jev 판단 근거 · 판단·주문 기록 · 증권사 잔고·주문 원본 · 전략·AI 설정).
- 정책 설명 문구는 "전략·AI 설정" 탭 목록으로, 중복 평가 카드는 제거했다. 오류·경고는 해당 위치에서 조건부로만 표시한다.
- 차트 의견 글자: 의견 변경 시 "Jev매수 0.42", 기준 최초 충족 시 "충족", 그 외 5분마다 신뢰도 숫자.

## 매매 기준 카드와 설정 (2026-11-11)

상태 줄 바로 아래에 "매매 기준" 카드(매수: Jev 매수 신뢰도·분봉 상승·추가 매수 간격 / 매도: 절반·전량 익절 %, 손절 %, Jev 매도 신뢰도)를 둔다. 값은 `strategy-settings.json`(없거나 잘못되면 기본값)에서 읽고 출처(기본값/사용자 설정/잘못된 파일)를 표시한다. "전략·AI 설정" 탭 맨 위 폼에서 6개 값을 범위 안에서 바꾸고 저장·기본값 복원하며, 실행기 적용 기록(`strategy_settings` 이벤트)을 보여준다. 보유 막대와 차트 기준선(손절·절반 익절·전량 익절)도 같은 값을 쓴다.

## 화면 안내·도식 가이드 (2026-11-12, ui-ux-pro-max)

- 원칙: 도움말은 모든 탭에서 같은 자리(탭 첫 줄 오른쪽)에 둔다(WCAG 2.2 Consistent Help). 짧은 설명은 팝오버, 도식은 큰 대화상자로 나눠 단계적으로 보여 준다. 가이드는 언제든 닫을 수 있다.
- 탭 첫 줄: 화면 목적 한 문장 · "화면 안내" 팝오버(이 화면은 / 읽는 순서 / 용어) · "도식 가이드" 버튼. 사이드바 맨 위 "가이드 센터"는 같은 대화상자를 연다. 도식 버튼은 팝오버 안에 두지 않는다(열린 팝오버가 대화상자를 가린다).
- 대화상자: 화면 선택 + 탭(이 화면 · 매수 전략 · 매도 전략 · 시장 국면 · 안전장치 · 실계좌 · 데이터 흐름). 도식은 Graphviz(브라우저 렌더), 매수=빨강 · 매도=파랑 · 가드=주황 · 대기=회색 테두리이며 글자로도 구분한다.
- 문구와 도식의 숫자는 `guides.values()`가 저장된 매매 기준과 실행기 상수에서 읽는다. 코드와 설명이 따로 놀지 않게 하려는 것이다. 내용은 `streamlit_namuh/guides.py` 한 곳에 있다.
- 실계좌 탭 재구성: 상태 카드 4개(실행기 · 신규 매수 · 주문 보호(HALT) · 마지막 기록) → 관찰 상태 안내 → 보호 한도 카드 4개(운용금 · 하루 손실 · 1회 주문 · 종목 손절) → 주문 경로 도식(펼침) → 하위 탭(잔고·주문 한 번에 조회 / 자동매매 제어 / 모의→실계좌 적용 검토). 카드마다 (?) 툴팁에 뜻과 주의점을 둔다.
- 대시보드 서버는 `scripts/`의 모듈을 다시 읽지 않는다. 실행기 상수나 가이드 모듈을 바꾸면 대시보드 서비스를 재시작한다.

## 상단 상태 카드 · 색 · 아이콘 · 깜박임 (2026-11-12)

- 모든 탭 상단 지표는 `streamlit_namuh/status_cards.py`의 카드로 통일한다. 카드는 왼쪽 굵은 테두리 색, 은은한 바탕색, Material 아이콘, 값 글자색, 상태 점으로 상태를 보여 준다.
- 색 의미: 빨강=상승·강세·수익·매수(한국 관례), 파랑=하락·약세·손실·매도, 초록=정상·실행 중·허용, 주황=주의·혼조·기준 미달·미등록, 장미색=중단·오류·확인 불가, 보라=AI(Jev·vibe) 의견, 회색=꺼짐·없음. 상태는 항상 글자와 아이콘으로도 쓴다(색만으로 전달하지 않음).
- 깜박임: 작은 점만 1.6초 주기로 천천히 깜박인다(초당 3회 미만). 깜박이는 경우는 진행 중(실행 중·진입 가능 시간대·장중 최신 기록·오늘 체결 있음)과 경고(장미색 카드는 테두리까지)뿐이다. 사이드바 "상태 깜박임"으로 끌 수 있고, 시스템의 "동작 줄이기"에서도 멈춘다(WCAG 2.2.2, 2.3.1).
- 적용 위치: 시장 상황(국면 2 · 시장 폭 · 분석 시각), 전략 구조(시간대 · 엔진 · 자동매매 · 지수 국면 · 추가 매수), 트레이딩 현황(평가손익 · 주문가능금액 · 보유/체결 · 최근 Jev/vibe), 모의 주문·정리, 모의 AI 기록·운영 상태(하루 요약), 실계좌(상태 · 보호 한도), 실계좌 가상 실행.
- 트레이딩 현황은 숫자 카드를 맨 위에 두고, 긴 매매 기준 설명은 "매매 기준 (지금 적용 중)" 펼침으로 내렸다.
- 진입 기준 표시는 고정값 0.6을 지우고 저장된 설정(`entry_confidence` · `sell_confidence`)을 읽는다.

## 트레이딩 현황 계좌 전환 · Jev vs vibe-trading 재설계 (2026-11-13, ui-ux-pro-max)
