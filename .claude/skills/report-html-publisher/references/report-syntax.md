# 리포트 가독성 문법 (HTML 페이지·대시보드 공통)

리포트 원본(.md)에 아래 문법을 쓰면 HTML 페이지에서는 상자·강조·차트·흐름도로 그려지고, 대시보드(st.markdown)에서는
색 라벨·배경 강조·"HTML에서 보기" 한 줄로 바뀐다(`report_figures.for_streamlit`). 템플릿 절 제목·순서는 바꾸지 않는다.

## 맨 앞 인용은 페이지 요약이 된다
제목(`# …`) 바로 아래 첫 인용(`> …`)은 페이지 머리의 요약 한 단락으로 올라가고 본문에서는 빠진다(같은 말 두 번 방지).
그래서 본문에 꼭 남겨야 할 안내(예: "샘플 리포트")는 첫 인용이 아닌 첫 문단이나 콜아웃 뒤에 둔다. 첫 인용이 `> [!SUMMARY] …`
같은 콜아웃이어도 요약에는 표식 없이 글만 들어가고, 요약에서는 `**`·`==` 같은 꾸밈이 빠진 평문으로 보인다.

## 콜아웃: 한 절에 하나, 꼭 필요한 곳에만
```
> [!SUMMARY] 오늘의 결론        ← 제목은 선택. 없으면 '요약'
> 코어는 유지하고 위성 반도체만 −15% 타점에서 1/3 추가 매수한다.
```
| 표기 | 라벨 | 쓰는 곳 |
|---|---|---|
| `[!SUMMARY]` | 요약 | 절의 결론 한두 문장(절 맨 앞) |
| `[!IMPORTANT]` | 중요 | 오늘 반드시 알아야 할 사실 하나 |
| `[!WARNING]` | 주의 | 조건부 위험, 확인 전 행동 금지 |
| `[!CAUTION]` | 위험 | 손실·규칙 위반·데이터 오류 |
| `[!TIP]` | 팁 | 다음에 해 볼 개선·확인 방법 |
| `[!NOTE]` | 참고 | 출처·한계·용어 설명 |
한글 표기(`[!요약]`·`[!중요]`·`[!주의]`·`[!위험]`·`[!팁]`·`[!참고]`)도 된다. 남발하면 강조가 사라지므로 한 절에 하나를 넘기지 않는다.

## 문장 강조
- `**굵게**`: 숫자·종목·결론 같은 핵심어(문단마다 1~2개).
- `==형광펜==`: 그 절에서 꼭 기억할 한 구절(리포트 전체에 2~4개).
- `*기울임*`: 용어 첫 등장(밑줄로 보인다).

## 표 → 자동 막대
첫 열이 이름이고, 머리글에 `등락`·`수익률`·`손익`·`변화`·`증감`·`대비`가 든 열이 부호 있는 숫자면(3행 이상) 표 아래에
"…한눈에 보기" 막대가 자동으로 붙는다(상승 빨강·하락 파랑). 숫자에는 `+`/`−` 부호와 단위(%·원)를 붙여 쓴다.

## 차트 블록 (```chart)
표로는 흐름이 안 보일 때만. JSON 한 덩어리.
```chart
{"type": "line", "title": "가상 계좌 순자산(억 원)", "unit": "억",
 "series": [{"name": "가상", "points": [["11-13", 1.0], ["11-14", 1.012], ["11-17", 0.991]]},
            {"name": "기본 그림자", "points": [["11-13", 1.0], ["11-14", 1.006], ["11-17", 0.995]]}]}
```
```chart
{"type": "bar", "title": "종목별 실현손익", "unit": "원", "data": [{"label": "114800", "value": -54328}, {"label": "069500", "value": 12000}]}
```
선은 4개까지, 점은 날짜 순. 값은 원본 데이터에서 그대로 가져오고 지어내지 않는다. 선 그래프는 화면 폭에 맞춰 늘어나고
축 글자 크기는 그대로라 휴대폰에서도 잘리지 않는다. 막대는 값이 막대 끝에 붙는다.

## 흐름도 (```archify-<종류>)
순서·분기·상태 변화가 핵심일 때만(리포트당 1개 권장). archify가 HTML 생성 때 그려 페이지에 넣는다(별도 파일, 다크 모드 연동,
`meta.animation`은 생성기가 늘 none으로 바꾼다).
종류: `workflow`(단계·분기, 예: 시나리오별 대응), `lifecycle`(상태 전이, 예: 국면 전이), `sequence`(주체 간 순서),
`dataflow`, `architecture`. 형식은 `~/.claude/skills/archify/examples/*.workflow.json` 등을 본보기로 쓰고,
`node ~/.claude/skills/archify/bin/archify.mjs validate workflow <파일>`로 먼저 검사한다. 실패하면 페이지에 '도식을 그리지 못했습니다' 상자가 남는다.

## 확인
`report_pages.py --preview <종류> <md>`로 그려 보고(기록·발송 없음) 1920·1440·390px, 라이트·다크를 본다.
