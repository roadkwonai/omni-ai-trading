# Omni CLI 분석

- 백엔드: `scripts/`의 파이썬 함수와 읽기 전용 명령. 다시 구현하지 않습니다.
- 상태: 파일과 DB가 원본이고 CLI는 상태를 갖지 않습니다. 계획과 승인만 `~/.vibe-trading/cli/cli.sqlite3`에 둡니다.
- 설정 주소: `strategy` `accounts` `lt` `book` `dca` `tunables` `ai` `prefs`. 쓰기 전에 실제 저장 함수를 복사본에서 돌려 결과를 계획으로 남깁니다.
- 승인 코드가 필요한 요청: 매매 요청 파일, 중단·재시작, 서비스 시작, 발송, 실주문 켜기·매수 재개·HALT와 STOP 해제·백업 가져오기(`core/actions.py`, 위험을 늘리는 것은 결과도 알림, 셋은 확인 문구까지). 유료 질문은 `--yes`와 하루 한도.
- 하지 않는 것: 증권사에 직접 주문, 새 종목 매수, 서비스 등록·`--execute` 변경.
- undo: 설정만 이력으로 되돌립니다.
