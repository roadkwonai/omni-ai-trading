## 실제 모의 API에서 확인한 증거

다른 실행이 같은 모의계좌를 사용한 흔적을 발견하여 신규 주문을 중단하고,
기존 기록을 현재 모의 API 조회와 대조했다. 이 검토 실행에서 신규 매수·매도·취소를 전송하지 않았다.

- 계좌목록에서 선택한 계좌가 `acct_type=03`임을 확인.
- 운영 조회 MCP의 `trading_enabled=false`, 국내 주문 API 노출 수 0 확인.
- 기존 미체결 매수 주문 312·328: 체결 0주, 취소 1주, 잔량 0주.
- 별도 실행의 매수 주문 421: 삼성전자 1주, 평균 체결가 185,100원, 잔량 0주.
- 매도 주문 439: 삼성전자 1주, 평균 체결가 187,500원, 잔량 0주.
- 현재 주문 조회에서 위 매수·매도 체결을 다시 확인. 모든 조회된 주문의 미체결 잔량 0주.
- 최종 잔고의 삼성전자 `itg_bnc_qty=0`. 보유수량 0인 잔고 행과 빈 종목코드 집계 행이 남을 수 있으므로 행 수로 포지션 유무를 판단하지 않는다.
- 원본 기록의 D+2 예수금: 5,000,000,000원 → 5,000,001,306원. 이는 단일 모의거래의 관찰값이며 전략 수익성 증거가 아니다.

기존 공개 보고서 `nhplug-paper-test-result.md`는 09:12~09:17 당시의 미체결 기록이다.
위 성공 기록은 09:33 이후 생성된 별도 실행 기록과 이번 재조회에서 확인한 것으로 시점을 구분한다.
원본은 `.venv/nh-paper-roundtrip-20261106-093343.json`, `.venv/nh-paper-sell-421.json`,
`.venv/nh-preflight-private.json`에 비공개 보관한다. 원본에는 계좌 데이터가 있으므로 공유하지 않는다.

## 재현용 검사

```bash
.venv/bin/python -m unittest discover -s scripts -p 'test_nhplug_*.py'
node scripts/test_nhplug_structured.mjs
# 기본 실행은 계좌·시세·주문 상태 조회만 수행한다.
.venv/bin/python scripts/nhplug_paper_smoke.py
```

`--execute`를 명시하면 빈 모의 포트폴리오와 미체결 주문이 없는 상태에서
삼성전자 1주, 최대 300,000원, KRX 지정가로 한 번의 매수·매도를 시도한다.
각 단계에서 최대 30초 조회 후 미체결분을 취소하고 잔량을 대조한다.
매수 체결과 잔고 증가가 모두 확인되어야 매도한다. 시장가·자동 재전송은 사용하지 않는다.
평일 한국시간 09:05~15:00 이외에는 신규 주문을 거부한다.
재실행 시 미확인 제출 기록이 있으면 주문하지 않는다. 해당 기록을 임의 삭제하여 우회하지 않는다.
동시 실행 잠금은 이 로컬 smoke CLI에 한정되므로 다른 앱·실행기가 같은 계좌를 사용하면 안 된다.
이 실행기의 잠금은 macOS/Linux의 `fcntl`을 사용한다.

네트워크 장애로 주문 조회·취소가 불가능하면 잔량 정리를 보장할 수 없다.
매도 미체결 시에는 모의 보유분이 남을 수 있으므로 `roundtrip_verified`가 아닌 결과를 성공으로 취급하지 않는다.
일반 Vibe NH MCP 주문에는 별도의 영속 제출 가드가 적용된다. smoke 실행기와는 상태 저장소가 다르므로 같은 계좌에서 두 경로를 동시에 운용하지 않는다.

공식 기준: [NH 안내](https://www.nhplug.com/llms.txt),
[국내주식 명세](https://www.nhplug.com/openapi-docs/krstock/openapi.json).

## 2026-11-06 일봉 스윙 설정 적용

사용자가 전략 모의 투자금 3,000만 원을 선택했다. 상세 규칙은 `namuh-paper.SKILL.md`의 일봉 스윙 프로필을 따른다.

적용: DART 공시·주요 재무·종목 고유번호 도구, KRX 완료일 원자료 조회 도구, 일봉 캐시와 데이터 소스 우선순위, NH 프로세스 간 토큰 공유 캐시, 모의 지정가 매수 한도·평일 시간창·수동 중단·기존 중복/불확실 주문 차단.

실제 조회 검증: 삼성전자 DART 공시 36건·2025 사업연도 주요 재무 항목 30개·종목 고유번호 매핑, Yahoo 2026-05-04~2026-11-05 일봉 125개. KRX는 HTTP 401이며 사용자가 키만 발급한 상태라고 확인했다. 유가증권 및 코스닥 일별매매정보 각각의 서비스 활용 신청·승인이 필요하다.

비밀키는 저장소 `.env`(스크립트용)와 에이전트용 `~/.vibe-trading/.env`(0600)에 두 데이터 키를 같은 값으로 둔다. 소스·보고서·도구 결과에 인증키를 넣지 않는다.

남은 범위: KRX 승인 후 실데이터 재검증, 휴장일 캘린더·손실 자동 중단·보유/손익 장부·거래 비용 검증·새 전략의 전진 모의평가·잔고 연속조회 처리. 현재 매수 금액 한도는 순노출이나 현재 보유액이 아니라 보수적인 누적 제출금액이다. 취소·매도 후 자동 복원하지 않는다.

운영 방법: 기존 웹서버를 재시작하면 신규 도구와 데이터 키 설정이 반영된다. 승인·설정 적용을 위해 신규 주문이나 상시 전략을 실행할 필요는 없다.

## 자동 중단·장 확인 후속 적용

모의 신규매수에 위험액 30만원 영속 중단과 KRX 시세 두 응답의 장 상태·시간 진행 검사를 적용했다. 자세한 범위와 한계는 `nhplug-order-safety.md`의 자동 손실 중단 절을 따른다. 이 기능은 정확한 일일 수익률 산출·미래 휴장일 달력·강제청산·상시 감시기가 아니다. 이전 절의 '미완료' 표시는 당시 상태로 보존하며 현재 적용 범위는 이 후속 절을 우선한다.
