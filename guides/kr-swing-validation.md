**판정: 연구·관찰용으로 보류. 자동 주문 전략으로 승급하지 않았습니다.**

## 고정 규칙

- 삼성전자·SK하이닉스·NAVER·현대차·KB금융의 고정 연구 바스켓. 현재 선정 종목을 과거에 적용한 선택·생존 편향이 있습니다.
- 종가 > 20일 이동평균 > 60일 이동평균이고 20거래일 수익률이 양수면 목표 비중 10%, 아니면 0%. 공매도·레버리지 없음.
- 신호는 당일 종가까지, 체결은 다음 관측 거래일 시가. 종목당 신규 매수 300만 원, 하루 매수 600만 원 이하. 실제 NH 허용 시간창(09:10 이후)의 체결가와는 다를 수 있습니다.
- 기본 비용 가정: 매수·매도 각각 수수료 0.20%, 매도세 0.20%, 각 체결 슬리피지 0.05%. 실제 API 계좌 수수료나 과거 연도별 법정세율의 재현이 아닌 보수적 고정 가정입니다.
- 결과를 본 뒤 파라미터 탐색을 하지 않았습니다. 성과 산출 전에 상태 기반 청산을 제거한 설계 수정과 원본 초안을 함께 보존했습니다.
