# Jev 종목별 프로그램 수급 모의 검증

TypeSafe 요청 형식이나 입력 구성, 오류 처리를 바꿀 때는 [Jev 개발·장애 대응 가이드](jev-typesafe-development.md)를 함께 확인한다.

`scripts/jev_program_paper.py`는 종목별 프로그램 수급과 차트를 결합한 가설을 1주 단위로 검증한다. 키움 KRX 종목시간별 프로그램 수급 `ka90008`의 누적 매수·매도 수량과 동일 종목의 완료 1분봉을 사용한다. 당일 누적 순매수와 최근 5분 순매수 변화량을 별도로 표시한다. 전자는 현재까지의 합이고 후자는 최근 압력의 방향이다. [키움 REST API 가이드](https://openapi.kiwoom.com/m/guide/apiguide)

| 시험 조건 | 진입 검토 | 미보유·보유 대응 |
| --- | --- | --- |
| 최근 순매수가 최근 거래량의 10% 이상, 직전 5분 대비 거래량 1.2배 이상, 5분 가격 +0.15% 이상, 최근 10분 거래량 가중 종가 위 | 진입 검토 | 기존 모의 보유 유지 |
| 최근 순매도가 최근 거래량의 10% 이상, 같은 거래량 조건, 5분 가격 −0.15% 이하, 최근 10분 거래량 가중 종가 아래 | 진입 보류 | 모의 보유 청산 검토 |
| 방향 불일치, 자료 누락·지연, 누적 수량 오류 또는 거래량 불일치 | 대기 | 모의 보유 유지 |

5분 구간의 시작·끝에서 각 1분 이내에 관측된 수급을 비교한다. 관측 간격이 5분에서 30초 넘게 벗어나거나 중간에 누적 매수·매도 수량이 줄면 그 구간은 건너뛴다. 거래소가 KRX로 명시되지 않은 응답 중 NXT나 통합 시세도 제외한다. 거래량 가중 종가는 1분봉 종가를 거래량으로 가중한 값이다. 이 기준은 초기 검증 가설이다.

```sh
PYTHONPATH=agent:scripts .venv/bin/python scripts/jev_program_paper.py 005930 --save /tmp/jev-program-005930.json
PYTHONPATH=agent:scripts .venv/bin/python scripts/jev_program_paper.py 005930 --input /tmp/jev-program-005930.json --at 10:15
PYTHONPATH=agent:scripts .venv/bin/python scripts/jev_program_paper.py 005930 --input /tmp/jev-program-005930.json --at 10:15 --ask-jev --held
```

첫 명령은 당일 자료를 새 파일에 저장한다. `ka90008`은 날짜를 바꿔도 당일 자료만 반환하므로 다른 날을 복기하려면 당일에 확보한 자료가 필요하다. 현재 한 페이지만 읽으며 필요한 구간이 빠지면 대기로 기록한다. 캡처에는 증권사 시세 자료가 포함되므로 로컬에 보관한다.

기본 재현은 위 조건만 사용한다. 신호가 나온 시각보다 1분 뒤 봉의 시가로 가상 체결하며, 비용은 기본 편도 15bp 가정이다. 14:30 신규 진입 마감과 15:00 정리를 적용한다. 다음 봉이 없으면 가상 체결 가격도 미확인으로 남는다. `--ask-jev`는 정규장 종료 후 지정한 시각의 차트·수급을 Jev에 한 번 전달한다. `--held`를 지정하면 기존 모의 보유를 가정한다. Jev가 시험 조건과 같은 의견을 낸 경우에만 진입·청산 검토를 가상 체결로 평가한다. 요청과 응답은 `~/.vibe-trading/nhplug/jev-program-paper/judgments.sqlite3`에 저장한다.

실계좌 1은 공유 모의 `orders.sqlite3`에 기록된 체결을 읽는다. 이 실험은 가상 체결을 실행 결과와 전용 모델 감사에만 남긴다. 운영 실행기, 주문 원장, 계좌 설정에서 실험을 호출하는 경로는 없다.

## 장중 감사와 수정 이력

```sh
PYTHONPATH=agent:scripts .venv/bin/python scripts/jev_program_audit.py
```

감사기는 09:10부터 15:20 전까지 최근 15분 내 기록된 Jev 후보·보유 판단을 대조한다. 보유 판단을 우선하며, 10분마다 최대 2종목의 수급과 분봉을 한 번씩 조회한다. 같은 회차가 재실행되면 이미 저장한 결과를 읽는다. 당일 거래일 시작 기록으로 장 운영을 확인한다. 휴장이나 확인 불가면 조회를 생략한다.

`~/.vibe-trading/nhplug/jev-program-paper/audit/YYYY-MM-DD/HHMM.json`에는 실제 Jev 판단의 시각과 입력 식별자, 수급 판단과의 불일치, 원본·유효 자료 수, 실패 사유와 재현 자료를 남긴다. 감사 파일을 `--input`으로 지정하면 해당 종목을 다시 재현할 수 있다. 실제 Jev가 판단한 뒤에 다운로드한 자료를 당시 시각에 맞춰 비교한 기록이다. 신호 불일치만으로 수익성이나 누락 체결을 판정하지 않는다.

| 적용일 | 재현된 문제 | 보완 |
| --- | --- | --- |
| 2026-11-26 | 시작·끝 시각 차이로 5분보다 짧거나 긴 구간을 비교할 수 있었음 | 관측 간격 검증과 실패 상태 기록 |
| 2026-11-26 | 구간 중 누적 초기화가 발생한 뒤 수치가 회복되면 끝점 검사만으로 놓침 | 구간 내 모든 초기화 시각을 검사 |
| 2026-11-26 | 동일 시각의 분봉 값이 다를 때 입력 순서에 따라 선택됨 | 충돌 봉을 제외하고 거래소 불일치 수급도 제외 |
| 2026-11-26 | 장중 대조 및 재현 자료 저장이 수동이었음 | 잠금과 10분 단위 캐시를 쓰는 별도 감사기 추가 |
| 2026-11-26 | 격리 Jev 요청에 시험과 관계없는 근거 질문이 포함됐음 | 수급 판단에 필요한 질문 하나만 보내고 실패와 모의 결과도 시험 DB에 저장 |

## 추세형 잔량 익절 실험

장중 감사의 `trend_exit_shadow`는 추세형이며 1차 익절 체결이 확인된 잔량만 검토한다. 완료된 1분봉 10개를 사용한다. 거래대금은 분봉 종가에 거래량을 곱한 추정값이다. 매도 우위는 하락 봉에 실린 거래량과 당시 호가 잔량으로 살핀다. 뉴스는 해당 Jev 판단에서 기록된 시장 뉴스 방향을 보조 근거로 쓴다. 종목별 뉴스의 영향은 따로 점수화하지 않는다.

- 수익률 +5% 이상에서는 고점 대비 0.5% 이상 반락했거나, 최근 5분에 +2% 이상 올랐지만 차트 약화·프로그램 순매도·매도호가 잔량 우위가 나타나면 전량 익절을 검토한다. 차트가 상승하고 거래량과 거래대금이 직전 구간의 90% 이상 유지되며 확인된 매도 압력이 없으면 추적청산을 이어 간다.
- 수익률 +0.8% 이상에서 종가가 단기 평균 아래이고 하락 봉 거래량이 우세하면, 프로그램 순매도·매도호가 잔량·거래량과 거래대금 증가·시장 뉴스 약세 중 하나 이상이 뒷받침할 때 잔량 청산을 검토한다.
- 감사에는 자료 기준 시각과 Jev 답변·뉴스 근거를 확보한 시각을 구분해 남긴다. 청산 검토 뒤 2분 안에 같은 수량의 다음 매수호가가 관측되고 실제 잔량 청산을 확인한 경우에만 비용 전 차이를 계산한다. 다음 호가 전 체결이 생기거나 비교 자료가 없으면 차이를 계산하지 않는다. 이 결과는 운영 주문에 연결되지 않으며, 관측 매수호가로 실제 체결이 가능했는지는 확인할 수 없다.
